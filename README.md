# 📘 Physical AI & Humanoid Robotics  
### An AI-Native Textbook with RAG-Powered Learning Assistant

This repository contains a **complete AI-native technical textbook** developed as part of  
**Hackathon I: Create a Textbook for Teaching Physical AI & Humanoid Robotics**  
organized by **Panaversity**.

The project bridges **Artificial Intelligence and Embodied Robotics**, enabling students to
learn Physical AI concepts through an interactive textbook enhanced with an AI-powered
Retrieval-Augmented Generation (RAG) chatbot.

---

## 🚀 Key Features

- 📚 **Docusaurus-based Technical Textbook**
- 🤖 **Integrated RAG Chatbot**
  - FastAPI backend
  - OpenAI Agents / ChatKit SDK
  - Neon Serverless PostgreSQL
  - Qdrant Cloud Vector Database
- 🔍 Ask questions about:
  - Entire book
  - Selected text only (context-aware Q&A)
- 🌐 Deployed for public access (Book + Chatbot)
- 🧠 Designed for **Physical AI & Humanoid Robotics education**
